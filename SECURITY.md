# Security policy

## Reporting

Report security and safety problems privately through **Security > Report a vulnerability** on this repository, not in a public issue. This includes:

- a removal of anything outside the item shown in the report;
- a path that should be refused (see [SAFETY.md](SAFETY.md)) getting through;
- a removal that reaches outside its folder, for example through a link;
- a network connection, or use of administrator rights.

Include what you ran, what happened, the rule id and path (replace your user name with `%USERPROFILE%`), the run record from `%LOCALAPPDATA%\Winnow\runs` if something was removed, and your Windows and PowerShell versions.

## Supported versions

Only the latest release.
